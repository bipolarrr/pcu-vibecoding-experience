# 시연 세션 운영 규약

## 시작 상태 확인

1. 첫 작업 전에 Git 저장소 루트에서 `npm run showcase:status`를 실행한다.
2. 명령의 종료 코드가 `0`이면 기존 작업 트리의 변경을 현재 시연 상태로 유지하고 작업을 계속한다.
3. 명령의 종료 코드가 `10`이면 자동으로 초기화하지 않고 시연 변경을 중단한 뒤 운영자에게 `npm run showcase:reset`이 필요하다고 알린다.
4. 상태 확인에 실패하면 시연 변경을 중단하고 운영자에게 오류를 보고한다.
5. `npm run showcase:baseline`은 운영자가 명시적으로 요청한 경우에만 실행한다.
6. 시연 세션에서는 Git commit, tag, pull, push를 실행하지 않는다. 운영자가 명시적으로 요청한 경우에만 예외로 한다.

## 변경 누적

1. 사용자가 초기화를 명시적으로 요청하기 전까지 기존 활성 기능과 디자인을 유지한다.
2. 새 요청은 `src/features/enabled.js`의 현재 활성 목록에 누적한다.
3. 기존 기능은 사용자가 제거를 요청했거나 새 기능의 `conflicts`·`replaces`에 해당할 때만 제거한다.
4. `npm run showcase:reset`은 사용자가 명시적으로 초기화를 요청한 경우에만 실행한다.

## 적용 범위

저장소 루트의 `AGENTS.md`에 명시된 기능 활성화, 다국어, 검증 및 완료 응답 규약을 함께 적용한다.
